Purpose
-------
A compile-tested Swift package and additive Swiftlet overlay for making the
Ornith-1.5-35B-A3B text checkpoint explicit, validating its qpack container,
and planning Swiftlet's global streamed-expert cache from a hard memory target.

Validation included in this archive
-----------------------------------
- 27 standalone Swift tests passed on Swift 6.2.1 / x86_64 Linux.
- 12 Swiftlet-overlay smoke tests passed against the reviewed upstream API surface.
- Release build and inspection CLI passed.
- Swift formatting, shell syntax, fixture JSON, patch application, and installer safety passed.

Important scope boundary
------------------------
This is an integration overlay and reference implementation, not a claim of a
completed production Metal port. It deliberately reuses Swiftlet's existing
Qwen3.5 MoE/DeltaNet graph and qpack runtime. Full token/logit parity, Apple
Metal compilation, real-checkpoint repacking, and throughput measurements must
be run on Apple Silicon with the official checkpoint.
